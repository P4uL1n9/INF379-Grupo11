# Fuentes de Datos

## Dataset utilizado

- Nombre: Best Books Ever Dataset
- Archivo usado en este proyecto: `books_1.Best_Books_Ever.csv`
- Origen: Kaggle
- URL: https://www.kaggle.com/datasets/pooriamst/best-books-ever-dataset/data

## Descripción general

Este dataset contiene información de libros, incluyendo variables como:

- Identificador y título del libro.
- Autor/a y serie.
- Géneros (lista de géneros por libro).
- Rating promedio.
- Número de páginas.
- Idioma, editorial y fechas de publicación.
- Métricas de popularidad y valoración (por ejemplo, número de ratings).

En esta tarea, el dataset se utiliza para construir visualizaciones comparativas de géneros, ratings y evolución temporal.
